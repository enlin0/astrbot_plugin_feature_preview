# 功能预览（astrbot_plugin_feature_preview）

读取 Bot 已安装插件的名称与简介，在用户问“你可以做什么”“你有什么功能”时回复一份功能清单。展示哪些插件可以自由配置：自动读取全部已启用插件，或使用白名单/黑名单精确挑选。

- 插件类型：AstrBot Star 插件
- 兼容版本：AstrBot `>=4.16,<5`
- 依赖：无（仅使用 AstrBot 内置 API）

## 功能

- 自动读取 `context.get_all_stars()` 中的插件元数据：展示名、插件名、简介、版本、作者、启用状态。
- 命中触发词后回复纯文本清单，不写死任何插件名，装了什么就列什么。
- 三种展示策略：`auto`（全部已启用）、`whitelist`（只列指定插件）、`blacklist`（排除指定插件）。
- 可过滤 AstrBot 内置插件、已停用插件，以及插件自身。
- 可限制展示条数与单条简介长度，避免消息过长。
- 支持自定义开头、单条格式、结尾和空列表回复。
- 额外提供 `/功能`（别名 `/功能预览`）指令，随时手动查看。
- 触发词、匹配方式、展示策略等配置修改后立即生效，无需重载插件。

## 安装

把本目录放到 AstrBot 的 `data/plugins/` 下，然后在 WebUI 的「插件」页重载插件（或重载全部插件）。

目录结构：

```text
astrbot_plugin_feature_preview/
├── main.py
├── metadata.yaml
├── _conf_schema.json
└── README.md
```

## 使用

### 触发词

默认包含以下说法（包含匹配）：

- 你可以做什么
- 你能做什么
- 你会什么
- 你有什么功能
- 你有哪些功能
- 有什么功能
- 有什么插件
- 插件列表
- 功能列表

也可以发送 `/功能` 或 `/功能预览`。

群聊里默认不需要 @Bot，只要消息命中触发词就会回复。如果希望群里只在被 @、被引用或使用唤醒前缀时回复，把「群聊中需要 @ 或唤醒前缀」打开。

### 展示效果

默认配置下的回复类似：

```text
本 Bot 目前已安装这些插件：
1. 我要涩涩增强版：基于 Lolicon API 的可配置随机涩图插件，支持触发词匹配模式、数据源切换、本地缓存池。
2. 本地回忆[APLR]：轻量级本地记忆插件，使用本地 Embedding 模型、本地数据库存储和回忆聊天记录。
3. 功能预览：读取已安装插件的名称与简介，在用户询问“你可以做什么”时回复功能清单。
共 3 个插件。
```

（本插件默认不展示自己，上面的“功能预览”只是示意。）

### 挑选要展示的插件

在 WebUI 的插件配置页调整：

| 配置项 | 说明 |
| --- | --- |
| 插件展示策略 | `auto` 全部已启用；`whitelist` 只展示白名单；`blacklist` 展示除黑名单外的插件 |
| 白名单插件 | 仅在 `whitelist` 下生效，可填 `astrbot_plugin_lolicon`、目录名、展示名或短名 `lolicon` |
| 黑名单插件 | 任何策略下都排除 |
| 展示已停用插件 | 停用插件会标注“（已停用）” |
| 展示 AstrBot 内置插件 | 默认隐藏 `builtin_commands` 等内置插件 |
| 展示本插件自身 | 默认隐藏“功能预览”自己 |
| 最多展示数量 | 0 表示不限制 |
| 简介最大长度 | 0 表示不限制 |
| 回复开头 / 单条格式 / 回复结尾 | 支持占位符，见下表 |
| 没有可展示插件时的回复 | 过滤后为空时使用 |

### 模板占位符

`单条插件格式` 支持：

| 占位符 | 含义 |
| --- | --- |
| `{index}` | 序号 |
| `{name}` | 插件展示名 |
| `{plugin_name}` | 插件名 |
| `{id}` | 插件 ID（作者/插件名） |
| `{desc}` | 插件简介 |
| `{version}` | 版本 |
| `{author}` | 作者 |
| `{status}` | 停用标记，启用时为空 |

`回复开头`、`回复结尾` 额外支持 `{count}`（实际展示条数）。

例如只列名字和版本：

```text
{index}. {name} v{version}
```

## 实现说明

- 通过 `self.context.get_all_stars()` 读取插件注册表，因此只反映 Bot 当前实际加载的插件。
- 只读取元数据中的名称与简介，不读取插件配置，不会泄露 Token 等敏感信息。
- 使用 `@filter.event_message_type(EventMessageType.ALL)` 监听消息，因此群聊中无需 @ 也能触发；如需限制可开启 `require_at_in_group`。
- 简介中的换行会折叠为空格，过长时截断，保证不同平台都能正常显示纯文本。
- 参考文档：[AstrBot 插件开发指南](https://docs.astrbot.app/dev/star/plugin-new.html)
